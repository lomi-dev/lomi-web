# lomi web

A minimal, English-language work-in-progress page for lomi.

## Run locally

```sh
bun install --frozen-lockfile
bun run dev
```

Open http://localhost:4321.

```sh
bun run check
bun run build
bun run preview --port 4322
```

## Page and stack

A single full-height hero contains the lomi wordmark, a work-in-progress message, and a link to the project on GitHub. The original realistic sky is static. The page intentionally has no navigation, product screenshot, downloads, FAQ, or footer while the new website is being prepared.

Colors follow the supplied lomi system v1.3 light theme: Soft Chalk (`#F7F8F3`) for the canvas, Ink (`#0B0D0C`) for primary text, and Electric Lime (`#C8FF3D`) for the primary action. Secondary text, hover, pressed, focus, and selection colors also use the original semantic tokens. The existing cloud photograph receives a static grayscale treatment and a uniform Chalk wash; the original asset is unchanged.

- Bun, Astro, React, TypeScript, and Tailwind CSS.
- Static HTML with no client-side JavaScript, hydrated islands, or animation code.
- React renders the inline SVG icons at build time; no React runtime is downloaded.
- Responsive AVIF/WebP clouds with a PNG fallback, generated by Astro.
- Local Geist and Instrument Serif fonts, preloaded with `font-display: swap`.
- Semantic landmarks, visible keyboard focus, and a skip link.
- No trackers, third-party embeds, or external font requests.

## Editing

- `src/pages/index.astro`: hero content and the GitHub link.
- `src/styles/global.css`: typography and responsive composition.
- `src/components/CloudBackdrop.astro`: the static background.
- `src/data/site.ts`: page metadata and project links.
- `src/layouts/Layout.astro`: metadata and local fonts.

The previous full landing page's unused components, screenshots, and product data are retained in the source for future work. They are not imported by the work-in-progress page.

Cloud provenance and the original generation prompt are recorded in [docs/assets.md](docs/assets.md). `public/social-card.png` is a 1200 × 630 browser render of the current hero for link previews.

## Verify

Build and start the production preview first, then:

```sh
PLAYWRIGHT_CHANNEL=chrome bun run verify
```

For Firefox:

```sh
bunx playwright install firefox
VERIFY_BROWSER=firefox bun run verify
```

Override the preview URL with `VERIFY_URL`. The check covers six viewport widths, a short landscape screen, the GitHub link, keyboard access, JavaScript-disabled rendering, no client scripts, and mobile/desktop accessibility with axe. Screenshots and audit output go to ignored `artifacts/`.

## Publish

Set the real public origin at build time and upload `dist/` to a static host:

```sh
SITE_URL=https://your-domain.example bun run build
```

`SITE_URL` enables canonical and absolute Open Graph URLs. `_headers` configures caching and basic security headers on hosts that support the file.
