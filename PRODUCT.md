# Product

## Platform

web

## Product Purpose

Lomi's website presents an open-source desktop workspace for coding agents,
an editor, terminals, browser previews and Git. It helps visitors understand
the workspace, follow development and obtain the application.

## Capabilities and Constraints

- The website uses the existing Astro application and published CMS content.
- Desktop downloads support macOS, Windows and Linux. Arch Linux also has
  `lomi-bin` and `lomi` packages in the AUR.
- Installer availability comes from published stable GitHub releases.
- No invented download links, release versions, dates or compatibility claims.
- The download task uses a dedicated page; the former dialog is removed.
- `/remote/` presents installation commands for the sibling `lomi-remote` project.
- Remote installation commands use the exact Unix and PowerShell commands
  supplied by the project owner. The installer scripts are published separately;
  both target URLs returned HTTP 404 during verification on 2026-10-20.
- The Remote host's native Rust/CLI/local terminal foundations are distinct from
  planned remote transport and desktop/web/mobile integration. The desktop
  screenshot shows the lomi workspace rather than a Remote dashboard.
- Do not promise production E2EE, complete File/Git services, reboot recovery or
  fully self-hosted account/relay infrastructure for this host.

## Brand Commitments

Preserve Lomi's existing name, logo and visual system. The download experience
uses the homepage's light canvas, Geist typography and lime primary action.
Real product imagery, clear download choices and restrained composition lead
the page, following the user's DB Pro, Cap and Devin references.
The download chooser groups system, format and action in one column beside
supporting product imagery. The Arch Linux command appears only when Linux
is selected and precedes the screenshot on small screens. System icons use
the original Iconify Simple Icons geometry, served locally.
